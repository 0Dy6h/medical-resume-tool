# 用户上手指南（5 分钟）

这份指南写给第一次使用本工具的求职者。全程本地运行，你的履历数据只存在自己电脑上。

## 这个工具是做什么的

它帮你做两件事：

1. **盯岗位**：自动抓取各医院、高校、疾控等机构的公开招聘公告，汇总成一个可搜索、可筛选的岗位库。
2. **写简历**：针对某个岗位，从你填写的真实履历中挑出与岗位要求对应的经历，生成一份带证据的定制简历草稿，可导出 DOCX/PDF。

它**不会**替你编造任何经历——简历里每一句话都来自你填过的内容；岗位要求里你没有的部分，会明确列为「缺口」提示你，而不是自动补齐。

## 第 1 步：注册并登录

打开工作台后，在登录页切换到「注册」，设置用户名（2-32 个字符）和密码。每个账号的履历和简历草稿相互独立。

## 第 2 步：加载岗位样本

- **第一次使用 / 演示**：在「总览」页点击「加载 fixture 样本」，系统会用 6 家内置演示机构加载稳定样本，先跑通全流程。
- **正式使用**：到「抓取任务」页，选择带「真实数据」标记的机构（如南方医院、浙大二院、北京大学医学部等），点击「启动」抓取最新公告。抓取是公开网页访问，不登录任何招聘平台账号。

抓取完成后，「岗位库」即可看到岗位。每天 09:00 系统会自动抓取一次全部启用机构（服务保持运行时）；错过时钟点后重启服务也会自动补跑。

## 第 3 步：看懂岗位库

- **筛选**：顶部可按关键词、大类、地区、机构类型、学历筛选。
- **数据可信度**：`真实数据` 来自已适配的官网；`占位·待复核` 是通用解析器的产出，仅供参考；`演示数据` 是内置 fixture。
- **匹配度列**（登录并填写履历后出现）：显示「满足 X/Y 项」——Y 只统计能与你履历对比的要求（学历、专业、技能等），悬停可见完整说明「满足 X/Y 项硬性要求」；国籍、年龄、身体条件等报名资格条款不参与统计，请以公告原文为准。显示「以公告原文为准」表示该岗位没有可自动比对的条款。
- **「硬性不符」红标**：学历等硬性门槛不满足（例如岗位要求博士、你是硕士）。

## 第 4 步：填写履历

到「我的履历」页：

- 顶部可切换「应届生 / 职场人」模式，板块均为非必填，按需填写。
- 支持从 DOCX / TXT / Markdown / 图片导入后勾选合并；图片和扫描 PDF 的识别需要本机安装 Tesseract OCR（未安装时请改用 DOCX 或文本导入）。
- 填完记得点「保存」。

## 第 5 步：生成简历草稿

到「简历生成」页，选择目标岗位，点「生成」：

- **如果被拦截**：提示「档案与该岗位要求差距较大」说明硬性门槛不满足（多为学历）。页面会给出「去岗位库按学历筛选」按钮，建议改投匹配岗位。
- **生成成功**：右侧展示每条岗位要求的匹配证据（用了你哪条经历）和缺口（未找到对应证据的要求）。

## 第 6 步：逐条审阅后导出

草稿默认处于「待审阅」状态。每一项内容都要做出决策：**采纳 / 修改 / 删除**。全部决策完毕（状态变为「已审阅」）后才能导出——这是防止未经确认的内容流入投递版的强制护栏。

- **导出 DOCX / PDF**：投递版，自动隐藏缺口诊断。
- **诊断版导出**：显式选择 `diagnostic` 模式，保留匹配分析，仅供自己参考。

## 订阅与通知

岗位库左侧可新建关键词订阅（如「护理」「公卫」）。每天自动抓取后会扫描新岗位并推送站内通知（顶栏铃铛）；也可手动点「检查更新」。

## 常见问题

- **匹配度一直 0/0 或「以公告原文为准」**：该公告的要求在附件里或全部是资格条款，请点开详情阅读原文。
- **生成按钮报「请先填写或导入履历内容」**：履历是空的，先完成第 4 步。
- **数据是最新的吗**：「抓取任务」页可查看每次抓取的时间和结果；总览页的岗位数即当前库中样本量。
- **隐私**：全部数据存在本机 SQLite（`backend/data/app.db`），不上传任何第三方服务。
