# 医疗岗位情报与真实简历定制工具 — 内测邀请

## 一句话

**不编故事，只用真履历**——从公开官网抓岗位情报，自动匹配你的真实经历，生成带证据链的定制简历。

---

## 为什么做这个工具？

医疗求职市场信息分散：30家头部机构的招聘公告散落在各自官网，有的藏在PDF附件里，有的混在新闻列表中。手动收集费时费力，投递简历时又常陷入"经历太多不知道写哪条"或"要求太细不确定自己符不符合"的困境。

更要命的是，很多简历生成工具为了"填满空白"会建议你**编造项目、夸大成果、虚构证书**——短期或许能过初筛，但一旦进入面试或背调，这些泡沫就是定时炸弹。

**我们的答案很简单：只用你提供过的真实履历事实，明确告诉你哪些匹配、哪些缺失，绝不帮你编故事。**

## 核心能力

### 1. **岗位情报自动抓取**
- 覆盖30家种子机构（三甲医院、医学院校、CDC、研究所），当前启用12家
- 支持从招聘公告HTML页面和公开xlsx/xls附件中提取岗位表
- 每条岗位保留**来源URL、内容哈希、抓取时间、解析器名称**——可追溯，可复查

### 2. **市场分析报告**
- 按岗位类别、学历要求、地区分布、机构类型、能力标签自动聚合
- 解析器质量监控：低置信岗位、附件解析失败、平均置信度一目了然
- 生成Markdown + 语义化HTML报告，明确说明"仅基于当前样本，不代表完整市场"

### 3. **真实履历约束下的简历生成**
- 你维护结构化履历：教育、工作/实习、科研项目、论文、教学、获奖、证书、技能、语言（所有部分均为非必填，按需填写）
- **支持上传 Word 简历（.docx）自动识别**：系统规则解析文档，按板块抽取条目，预览勾选后合并进你的履历，再增删改查——不用从零手敲
- 系统将履历扁平化后与岗位需求规则匹配，输出三层结构：
  - **sections**：简历各章节，每项标注`profile_field_id`指向你的原始履历字段
  - **evidence**：匹配到的证据列表，清晰展示"用了你的哪条经历"
  - **gaps**：未匹配需求明确提示"未在你的履历中找到对应证据"——**不建议编造，不自动生成虚假内容**
- 导出DOCX/PDF，支持中文字体，保留格式

### 4. **多用户账号，数据隔离**
- 用户名+密码注册登录，每个人的履历和简历草稿独立存储、互不可见
- 岗位库、市场分析等公共情报对所有登录用户共享
- 登录态用签名 token 保持，不接第三方账号

### 5. **顺手的工作台体验**
- 抓取任务后台执行，实时显示进度与成功/失败计数，支持机构全选/全不选/仅已启用
- 岗位库多维度筛选（关键词、大类、地区、机构类型、学历）+ 分页
- 全局操作反馈：保存、导入、导出、生成均有即时提示，出错不再"无声失败"

### 6. **本地可跑，数据自主**
- FastAPI后端 + SQLite数据库 + React前端工作台
- 不连第三方招聘平台账号，不做反爬绕过
- 全流程可在你自己的机器上完成

## 技术亮点

- **附件解析管线**：`openpyxl`解析公开xlsx岗位表，PDF附件当前记录证据待扩展
- **履历导入**：`python-docx`读取上传的Word简历，规则解析分节抽字段，无LLM、可预测、纯本地
- **账号与隔离**：标准库`scrypt`密码哈希 + `hmac`签名token，零外部依赖；履历/草稿按`user_id`隔离
- **多策略适配**：6个专用官网适配器（bjmu/chinacdc/nfyy/z2hospital/hrbmu/njmu）+ 通用解析器兜底
- **质量可观测**：每个解析器的岗位量、低置信量、附件成功/失败数、平均置信度全记录，标记`review/watch/stable`三档供人工抽样
- **证据链贯穿**：从岗位来源→履历字段→简历项→导出文档，每一步都有ID和时间戳，可回溯审计

## 适合谁？

- **医学生/医学博士**：找教职、科研岗、临床岗，需要同时关注多家机构，想快速了解市场热点和自己履历的匹配度
- **公卫/CDC从业者**：疾控、卫健委、研究所岗位信息分散，想集中查看并生成针对性简历
- **医疗行政/管理岗求职者**：需要快速定制简历应对不同机构的差异化要求，但不想每次从零手写
- **诚实主义者**：不愿意在简历上编故事，宁可明确知道自己哪里不足，也不要虚假通过初筛后被背调拆穿

---

## 当前限制（内测阶段）

- **样本覆盖有限**：30家种子机构中仅12家启用，不代表全国完整就业市场
- **解析器质量分层**：专用适配器质量较高，通用解析器置信度较低，需人工抽样复核
- **履历导入仅支持 .docx**：PDF、txt/Markdown、图片扫描件（OCR）识别在规划中，暂未上线
- **PDF岗位附件暂不解析**：当前仅记录PDF链接，不提取表格内容
- **简历生成规则较基础**：基于关键词重叠匹配，未来可扩展语义匹配或LLM增强
- **不支持反爬/登录平台**：只抓公开官网HTML和附件，不接第三方招聘平台账号
- **在线演示站HTTP未加密**：当前未配置域名和HTTPS，浏览器会提示不安全。账号密码与履历在网络上有被窥探风险，**请勿输入真实身份证、银行卡、住址等敏感信息**（本地部署无此限制）
- **单机SQLite无备份**：服务器数据库当前未配置自动备份，如需长期使用真实数据建议本地部署

## 如何参与内测？

**访问地址：`http://110.42.136.106/`**

部署在腾讯云上海服务器，Nginx + FastAPI + SQLite架构。

**注意**：当前HTTP未加密，浏览器会提示"不安全"，可忽略该提示继续访问（功能不受影响）。如需输入真实履历数据，建议等HTTPS配置完成或使用本地部署。

**操作流程**：
1. 打开 `http://110.42.136.106/`，**注册账号并登录**（用户名+密码，数据与他人隔离）
2. "抓取任务" → 全选或选择机构，启动后查看实时进度
3. "岗位库" → 多维度筛选，查看岗位详情、标签、来源证据
4. "分析" → 查看市场报告和解析器质量表
5. "我的履历" → 手动填写，或**上传 Word 简历（.docx）自动识别**后预览勾选合并
6. "简历生成" → 选目标岗位，检查证据和缺口，导出DOCX/PDF

## 项目原则（写在最后）

1. **不虚构履历事实**：系统只重组你提供过的字段，无履历证据的需求明确标记为gap，不建议编造
2. **不接平台账号**：不连智联/前程无忧/丁香人才，不做反爬绕过，只用公开官网
3. **不声称完整覆盖**：明确说明样本范围和局限性，不误导"这就是全市场"
4. **保留证据链**：每条岗位、每项匹配、每次导出都有来源、时间戳、parser名，可追溯
