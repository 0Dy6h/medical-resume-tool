医疗岗位情报与真实简历定制工具

项目原理图：从公开官网招聘信息和稳定 fixture 进入抓取解析链路，沉淀为可追溯岗位数据，再由分析服务与真实履历匹配服务支撑前端工作台。

Stack: FastAPI + SQLite + React/Vite
Scope: 本地 MVP · 公开官网样本
Invariant: 不虚构履历事实 · 保留来源证据

数据入口

  • • 前 6 家机构走 deterministic fixture，保证演示稳定。
  • • 6 个官网适配器抓公开招聘公告，通用解析器作为低置信兜底。
  • • xlsx/xls 附件可生成行级岗位；PDF 当前只保留证据。

处理闭环

  • • 后端负责抓取、解析、分类、去重、分析、报告和导出。
  • • SQLite 保存机构、任务、岗位、履历、草稿和报告。
  • • React/Vite 前端通过 REST API 形成求职工作台。

真实性约束

  • • 岗位必须保留 source_url、source_text_hash、fetched_at、parser_name。
  • • 简历生成只重组结构化履历里的事实，并记录 profile_field_id。
  • • 无履历证据的岗位要求进入 gaps，不编造经历或成果。
