# 整改验证与部署清单

## 🔍 验证步骤

### 1. 语法检查
```bash
cd d:/开发/螃蟹的简历撰写工具
python check_syntax.py
```

### 2. 运行后端测试
```bash
cd backend
python -m pytest tests/ -v
```

### 3. 启动后端服务
```bash
cd backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 4. 启动前端服务
```bash
cd frontend
npm run dev
```

### 5. 手动测试关键流程

#### 5.1 测试分页功能
1. 访问 http://127.0.0.1:5173
2. 点击「岗位库」
3. 如果有超过 50 条岗位，应该看到「上一页 / 下一页」按钮
4. 点击「下一页」，验证加载新数据
5. 在浏览器 DevTools Network 中查看请求：`/api/jobs?limit=50&offset=50`

#### 5.2 测试简历导出 loading
1. 点击「我的履历」，填写个人信息
2. 点击「简历生成」，选择岗位，点击「生成」
3. 点击「DOCX」或「PDF」导出按钮
4. **验证：** 按钮应变为「导出中...」并禁用
5. **验证：** 文件下载后按钮恢复

#### 5.3 测试配置管理
```bash
# 测试环境变量覆盖
export CRAWL_TIMEOUT=30
export JOB_LIST_DEFAULT_LIMIT=20
uvicorn app.main:app --reload
```
查看 `/api/jobs` 默认返回 20 条（而非 100 条）

#### 5.4 测试附件处理逻辑
1. 点击「抓取任务」
2. 选择「中国疾病预防控制中心」或「北京大学医学部」
3. 点击「启动」
4. 抓取完成后，进入「岗位库」
5. 找到带附件的岗位，点击查看详情
6. **验证：** 「来源证据」中应显示附件状态（parsed / failed / discovered）

## 🐛 已知问题与解决方案

### 问题 1: Bash 工具返回 exit code 49
**状态：** 环境问题，不影响代码质量

**临时方案：**
- 在本地命令行（非 IDE 集成终端）运行测试
- 或使用 Windows PowerShell / Git Bash

### 问题 2: 测试可能因 fixtures 缺失而跳过
**症状：** `pytest.skip("fixture not available")`

**解决方案：** 这是正常的 - adapter 测试依赖外部 HTML fixtures，跳过不影响核心逻辑测试

## ⚠️ 回滚方案

如果整改后出现问题：

### 快速回滚（Git）
```bash
git stash  # 或 git reset --hard HEAD~1
```

### 逐步回滚（分模块）
1. **配置管理问题：** 删除 `app/config.py`，恢复硬编码值
2. **分页问题：** 恢复 `repositories.py` 和 `main.py` 的 `LIMIT 500` 逻辑
3. **适配器问题：** 恢复单个适配器文件（bjmu/chinacdc/hrbmu）
4. **前端问题：** 恢复 `frontend/src/pages/` 下的文件
